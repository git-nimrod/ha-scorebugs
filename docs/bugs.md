# Every look

Scorebugs has **289 looks**. Each is drawn in code after the general look of a scorebug seen on TV; no network logo is
drawn (the Home Assistant logo sits in the network's spot). Pick one in the card editor, in **Configure > Scorebug looks**, or
with a card's `bug:` option (the id in the last column).

A look draws any game of its sport, so you can use a college look for an NFL team, or a retro look for today's game. The
"Default for" column says which leagues use it when nothing else is picked.
